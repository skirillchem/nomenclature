Интерактивный конспект

Номенклатура органических соединений

Как прочитать структурную формулу и шаг за шагом составить название: выбираем главную цепь, нумеруем её, определяем заместители, кратные связи и главную функциональную группу.

АлгоритмТаблицыРазбор примеровПроверь себя

1. Общий алгоритм

  1. Определи главную функциональную группу. Если групп несколько, выбери старшую по таблице ниже: она обычно задаёт суффикс.
  2. Выбери главную цепь. В неё по возможности включают главную функциональную группу и максимальное число кратных связей; затем выбирают наиболее подходящую длинную цепь.
  3. Пронумеруй цепь. Сначала добиваются наименьшего номера для главной группы, затем учитывают кратные связи и заместители согласно правилам выбранной номенклатуры.
  4. Найди заместители (метил-, этил-, гидрокси-, амино-, хлор- и др.) и укажи их положения.
  5. Собери название: положения и названия заместителей → название главной цепи с кратными связями → суффикс главной группы.
Важно. Это учебный алгоритм для типичных задач. В сложных случаях правила выбора главной цепи и старшинства уточняются по систематической номенклатуре IUPAC.

3. Разбор примеров

Открой каждый пример, чтобы увидеть ход рассуждений, а не только готовое название.

Алкен · галогенпроизводное

Пример 1. CH₃–CH(Cl)–CH=CH–CH₃

CH₃–CH(Cl)–CH=CH–CH₃

Разобрать по шагам

Шаг 1. Самая длинная цепь содержит 5 атомов углерода → корень пент-.

Шаг 2. Есть двойная связь, поэтому используем суффикс -ен. Нумеруем с правого края: двойная связь получает номер 2, а не 3.

Шаг 3. Атом хлора при C-4 → приставка 4-хлор-.

Итог. 4-хлорпент-2-ен.

Стереохимия двойной связи в этой формуле не задана, поэтому E/Z не указываем.

Спирт · разветвлённая цепь

Пример 2. CH₃–CH(CH₃)–CH(OH)–CH₂–CH₃

CH₃–CH(CH₃)–CH(OH)–CH₂–CH₃

Разобрать по шагам

Шаг 1. Главная цепь с –OH включает 5 атомов C → пентан.

Шаг 2. Нумеруем так, чтобы гидроксильная группа получила минимальный номер. С обеих сторон она может получить 3; сравниваем номера заместителей: метил получает 2 вместо 4.

Шаг 3. Главная группа –OH обозначается суффиксом -ол; метильный заместитель находится при C-2.

Итог. 2-метилпентан-3-ол.

Кетон · гидрокси как заместитель

Пример 3. CH₃–CO–CH₂–CH(OH)–CH₃

CH₃–CO–CH₂–CH(OH)–CH₃

Разобрать по шагам

Шаг 1. Главная группа — кетонная, поскольку в таблице она старше гидроксильной. Поэтому соединение называют как кетон.

Шаг 2. Цепь содержит 5 атомов C → пентанон. Нумеруем слева, чтобы карбонильный атом получил номер 2 (справа он получил бы 4).

Шаг 3. Кетон обозначаем суффиксом -он, гидроксильную группу — приставкой гидрокси-. OH находится при C-4.

Итог. 4-гидроксипентан-2-он.

Карбоновая кислота · галоген

Пример 4. CH₃–CH(Br)–CH₂–COOH

CH₃–CH(Br)–CH₂–COOH

Разобрать по шагам

Шаг 1. Карбоксильный углерод входит в главную цепь и всегда получает номер 1.

Шаг 2. Всего в цепи 4 атома C, включая углерод COOH → основа бутановая кислота.

Шаг 3. Считая от COOH, атом Br находится при C-3 → приставка 3-бром-.

Итог. 3-бромбутановая кислота.

Амин · алкен

Пример 5. CH₂=CH–CH(NH₂)–CH₃

CH₂=CH–CH(NH₂)–CH₃

Разобрать по шагам

Шаг 1. Цепь содержит 4 атома C и двойную связь → бутен.

Шаг 2. Аминогруппа — главная группа в этой формуле. Нумерация с левого края даёт двойной связи номер 1, аминогруппе — номер 3; при нумерации справа аминогруппа получила бы 2, но двойная связь — 3. Для данной учебной схемы выбираем минимальный номер кратной связи при сопоставлении вариантов.

Шаг 3. Указываем положения двойной связи и –NH₂, суффикс амина.

Итог. бут-3-ен-2-амин.

Примечание: в разных учебных курсах порядок приоритета нумерации кратной связи и суффиксной группы может подаваться по-разному; для систематического IUPAC-оформления следует придерживаться единого принятого стандарта.

Альдегид · оксо как приставка

Пример 6. CH₃–CO–CH₂–CHO

CH₃–CO–CH₂–CHO

Разобрать по шагам

Шаг 1. Альдегидная группа старше кетонной, поэтому суффикс будет -аль.

Шаг 2. Углерод группы –CHO входит в цепь и получает номер 1. Всего 4 атома C → бутаналь.

Шаг 3. Вторая карбонильная группа (кетонная) обозначается приставкой оксо-. От альдегидного углерода она находится при C-3.

Итог. 3-оксобутаналь.

Ароматическое соединение · нитро

Пример 7. C₆H₅–CH₂–CH(NO₂)–CH₃

C₆H₅–CH₂–CH(NO₂)–CH₃

Разобрать по шагам

Шаг 1. В качестве основной цепи берём пропан; фенильная группа и нитрогруппа будут заместителями.

Шаг 2. Нумеруем со стороны CH₃: нитрогруппа при C-2, фенильная группа при C-3. При обратной нумерации набор локантов тоже 2,3, поэтому сравниваем по алфавиту названия заместителей: фенил получает меньший номер.

Шаг 3. В названии перечисляем заместители: фенил- и нитро-; основа — пропан.

Итог. 2-нитро-1-фенилпропан.

Уточнение: структура C₆H₅–CH₂–CH(NO₂)–CH₃ при нумерации от фенильного конца даёт фенил не как заместитель основной пропановой цепи, а как фенильный заместитель при C-1; поэтому корректное имя в рамках этой модели — 1-фенил-2-нитропропан.

Простой эфир · алкокси

Пример 8. CH₃–O–CH₂–CH(CH₃)–CH₃

CH₃–O–CH₂–CH(CH₃)–CH₃

Разобрать по шагам

Шаг 1. Простой эфир в приложенной таблице не получает суффикс; его можно описать как алкокси-заместитель.

Шаг 2. Более длинная углеродная часть — 2-метилпропан. Группа –OCH₃ называется метокси-.

Шаг 3. Метокси-группа находится при C-1 главной цепи.

Итог. 1-метокси-2-метилпропан.

Нитросоединение · два заместителя

Пример 9. CH₃–CH(NO₂)–CH(Cl)–CH₃

CH₃–CH(NO₂)–CH(Cl)–CH₃

Разобрать по шагам

Шаг 1. Главная цепь — бутан, 4 атома C.

Шаг 2. С обеих сторон набор локантов 2,3. При равенстве первый по алфавиту заместитель получает меньший номер: хлор- перед нитро-.

Шаг 3. Записываем заместители и основу.

Итог. 2-хлор-3-нитробутан.
